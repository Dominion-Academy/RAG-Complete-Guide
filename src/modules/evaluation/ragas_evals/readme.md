## RAGAS совместимость

В pyproject.toml зафиксированы версии, совместимые друг с другом:
- ragas==0.3.9
- langchain-community<0.4

- Новые версии ragas (0.4.x) несовместимы с актуальным langchain-community и вызывают ошибку импорта vertexai. 
- Не обновляйте эти пакеты вручную без проверки совместимости.
